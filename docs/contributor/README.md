# The contributor documentation of thunderbox

This folder holds the documentation for a person who changes thunderbox. A
person who uses thunderbox reads [the user documentation](../user/README.md).

| document | what it holds |
|---|---|
| [Contributor guide](guide.md) | The documents to read, the tools, and the rules of each change. |
| [The architecture](architecture.md) | The parts of the program, and how they fit together. |
| [The decision records](adr/README.md) | One record for each decision, and for each question that remains open. |
| [Make the pictures again](pictures.md) | The scenes, and the commands that record a picture of each one. |
| [The research](research.md) | The evidence for the choice of each library. |
| [The open findings](open-findings.md) | The faults that a sweep of the repository found, and that no record holds yet. |
| [Rules of the project](rules.md) | The full rules of CLAUDE.md. These rules bind every contributor. |

[CLAUDE.md](../../CLAUDE.md) at the root holds the full rules of the project.
Claude reads it before each change, and its rules bind every contributor.
