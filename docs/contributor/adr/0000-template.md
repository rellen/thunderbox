# ADR NNNN: The decision, as one sentence

| field | value |
|---|---|
| Status | Accepted, Proposed, Superseded, or Rejected |
| Recorded | The date in the form 2026-11-20 |
| Source | The place that held the decision before this record, or `new` |
| Code | The files that hold the decision |
| Tests | The tests that fail when a person takes the decision out of the code |
| Related | The numbers of the related records |

## Context

State the problem, and state the forces that act on it. Name each fact that
a reader measured, and give the measurement.

## Decision

State the decision. Start with the words "The project" or with the name of a
part of the code. Use the present tense.

## Consequences

State what follows from the decision. State each cost, and each rule that a
later change must keep.

## Measurements

Remove this section when no reader measured anything. Give each measurement in
full: the command, the input, and the result.

## Designs that the project rejected

Remove this section when the project examined no other design. Name each
design, and name the fault that a reader measured in it.

## The question that remains

A record of the status Proposed keeps this section. State the work that
remains and what it is worth. Then state the question that the next design
must answer.
